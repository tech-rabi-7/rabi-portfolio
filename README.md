# Rabi Paul — Engineering Portfolio

Personal engineering portfolio showcasing software engineering projects, backend architectures, transit optimization algorithms, and technical credentials.

Built with React, TypeScript, Three.js, GSAP, and Vite.

## Tech Stack
- **Frontend / 3D**: React 18, TypeScript, Three.js, React Three Fiber, GSAP, Lenis Smooth Scroll
- **Styles**: Custom Vanilla CSS & Modular Design System
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/tech-rabi-7/rabi-portfolio.git

# Navigate to project directory
cd rabi-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
